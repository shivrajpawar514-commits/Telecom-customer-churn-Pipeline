Production Data & Target Drift Auditing

This interface compares baseline training schemas (reference dataset) with live inference data batches (current dataset) using Evidently AI. It uses statistical testing (Kolmogorov-Smirnov test, Chi-Square test, etc.) to detect changes in data distributions and target variables, preventing silent accuracy degradation in production.

Project Abstract

This system implements an end-to-end Machine Learning Operations (MLops) engineering pipeline designed to predict customer churn in telecommunications companies. Leveraging the IBM Telco Customer Churn dataset, we construct modular components for raw data ingestion, validation, preprocessing, model training, evaluation, registry, and serving. To guarantee reproducible pipelines, we employ Data Version Control (DVC), while MLflow manages training parameters, logs metric configurations, and hosts the Model Registry. The trained model is served via a containerized FastAPI application, configured with Docker, and provisioned in production on AWS ECS Fargate via a fully automated GitHub Actions CI/CD workflow. System durability and reliability are audited using Evidently AI drift analysis reports, closing the loop on continuous deployment, auditing, and retraining.
